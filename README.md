# @amlplugins/twilio-taskrouter

Native `twilio` SDK re-exported under the `@amlplugins` namespace.

> Twilio TaskRouter — skills-based task distribution engine for contact centers.

## Install

```bash
npm install @amlplugins/twilio-taskrouter
```

## Use

```ts
import { /* named exports from twilio */ } from "@amlplugins/twilio-taskrouter";
// or
import sdk from "@amlplugins/twilio-taskrouter";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
